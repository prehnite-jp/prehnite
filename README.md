# prehnite

Writing support software that helps you create coherent sentences

(整合性の取れた文章作成を支援する執筆支援ソフト)

## v0.0.1-alpha

This is the initial release.

(最初のリリースです。)

This version includes a data layer implementation and the ability to list items (headings and paragraphs).

(このバージョンでは、データ層の実装とアイテム(見出しと段落)を一覧表示する機能のみが存在しています。
)

Features such as text editing are not included.

(テキスト編集などの主要機能は存在しません。)
